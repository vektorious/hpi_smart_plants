# Legacy Instructions

These guides describe the **breadboard-based** build of the Smart Plants device using the
SEEED Studio XIAO ESP32-C6. They are kept for reference but are **no longer supported**.

The current PCB-based build is documented in `instructions/waveshare_pcb.md`.

| File | What it covers |
|------|---------------|
| `base_module_batteries.md` | Breadboard build, 3× AA battery power |
| `base_module_li-ion.md` | Breadboard build, 18650 Li-ion power |
| `pump_add-on.md` | Adding an automatic watering pump to the breadboard build |
