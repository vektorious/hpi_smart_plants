# Firmware image goes here

The flasher expects the merged firmware image at:

    web-flasher/firmware/smart_plants.bin

It is **not committed** — generate it with Arduino IDE or arduino-cli and copy it here.
See [`../README.md`](../README.md) → "Building / updating the firmware image".

Once `smart_plants.bin` is in this folder, the flasher page is ready to serve.
