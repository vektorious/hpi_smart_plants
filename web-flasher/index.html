🌱 Smart Plants Web Flasher

Install the Smart Plants firmware onto your board straight from the browser.

Your browser doesn’t support Web Serial. Use Chrome, Edge, or Opera on a desktop computer. Web Serial needs a secure (HTTPS) connection. Open this page over https://.
⚠️ First, put the board into flashing mode. The firmware deep-sleeps within seconds of booting, which disconnects the USB port — so you must start the board in its bootloader before flashing:
  1. Unplug the board.
  2. Hold the BOOT button down.
  3. Plug in the USB-C cable while still holding BOOT.
  4. Release BOOT after about 2 seconds.
The board now stays awake in flashing mode. Do this every time before you click Connect.

How to flash

  1. Put the board into flashing mode (BOOT-hold steps above), using a USB-C data cable.
  2. Click Connect above and pick the USB JTAG/serial debug unit port.
  3. Choose Install Smart Plants Firmware and wait for it to finish.
  4. When done, the board reboots. On first boot it opens a WiFi setup access point named <device>-Setup — connect to it to configure WiFi, device settings, and check live sensor readings.

Still can’t connect? On Linux, wait a couple of seconds after plugging in (a service may briefly hold the port). Make sure you’re using a data cable, not a charge-only one.

Firmware target: Waveshare ESP32-C6-Zero. See web-flasher/README.md in the repository for how the firmware image is built and updated.
